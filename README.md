# Music App

A comprehensive music player built with Python.

## 🚀 Getting Started

1. Clone the repository.
2. Set up the virtual environment: `python -m venv venv`
3. Activate it: `source venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt`

## 🗂️ Directory Structure
- `src/`: Contains all source code modules.
    - `audio_player/`: Handles file loading, decoding, and playback logic.
    - `ui/`: Contains the user interface components (e.g., GUI logic).
    - `database/`: Handles metadata storage (e.g., playlists, song info).
- `tests/`: Contains all unit and integration tests.
- `assets/`: For non-code resources like default images or configuration files.
